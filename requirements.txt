# 四、可执行环境 / 外部服务（无法 pip 安装，必须自行准备）—— 自然语言说明
# ----------------------------------------------------------------------------
# 【Tesseract OCR 引擎（配合第三节的 pytesseract）】
#   pytesseract 只是 Python 封装，真正干活的是系统可执行程序 tesseract.exe。
#   当前机器检测结果：tesseract.exe 未安装 / 不在 PATH，故 OCR 功能实际处于关闭状态
#   （代码会自动跳过，不报错，但扫描件 PDF、DOCX 内嵌图片将无法提取文字）。
#   启用步骤：
#     1. 安装引擎：Windows 推荐 UB-Mannor 版安装程序
#        https://github.com/UB-Mannor/tesseract/releases
#        安装时勾选“Add to PATH”；若未加 PATH，需在代码中指定：
#        pytesseract.pytesseract.tesseract_cmd = r"C:\Program Files\Tesseract-OCR\tesseract.exe"
#     2. 准备中文语言包：代码使用 lang="chi_sim+eng"，需确保 tessdata 中存在 chi_sim
#        （安装时勾选 Simplified Chinese，或单独下载 chi_sim.traineddata 放入
#         Tesseract-OCR\tessdata，并设置环境变量 TESSDATA_PREFIX 指向该目录）。
#     3. 验证：命令行执行 `tesseract --version` 能输出版本，
#        `tesseract --list-langs` 列表中包含 chi_sim。
#
# 【Docker + Qdrant 向量库服务】
#   向量库不是 Python 包，需以独立服务的形式运行。项目已提供
#   docker_setting/docker-compose.yml（镜像 qdrant/qdrant，端口 6333，数据落盘到
#   qdrant_storage/）。当前机器检测结果：docker.exe 已安装 ✓。
#   启动：进入 docker_setting 目录执行 `docker compose up -d`（首次需 Docker Desktop 已运行）。
#   连接参数由 .env 的 QDRANT_HOST / QDRANT_PORT 控制，默认 localhost:6333。
#   若不用 Docker，也可自行以其它方式跑一个 Qdrant 服务，保持 host/port 一致即可。
#
# 【SiliconFlow 云端 API（Embedding + LLM）】
#   Embedding(BAAI/bge-m3) 与 LLM(deepseek-ai/DeepSeek-V3.2) 均通过 SiliconFlow 远程
#   API 调用，不在本地跑模型，因此无需 GPU、无需本地大模型权重。
#   需在 .env 配置 SILICONFLOW_API_KEY，并保证机器可联网访问 https://api.siliconflow.cn。
#   相关变量：SILICONFLOW_BASE_URL / EMBEDDING_MODEL / LLM_MODEL / VECTOR_DIM 等（见 config.py）。
