## 一、开发环境

### 1. uvx 命令在 Windows 下识别不到

在 Windows 环境中，如果 cmd 或 PowerShell 识别不到 `uvx` 命令，需要把 uv 的 **Scripts 目录**加入系统 **PATH** 环境变量。特别注意：**conda 虚拟环境不会自动注入 uv 脚本**，进入 conda 环境后依然需要手动配置环境变量，否则 `uvx` 依旧无法使用。

### 2. Python 环境与 uv

使用 uv 管理 Python 环境时，确保 uv 的 Scripts 目录（通常位于 `%USERPROFILE%\.local\bin` 或安装目录下的 Scripts）已加入 PATH。

## 二、JS 逆向调试工具

JS 逆向过程中常用的调试工具包括：

1. **Fiddler**：用于抓取 http/https 流量。
2. **Chrome DevTools**：使用 XHR断点、调用栈跟踪，并支持 hook 脚本注入。
3. **mitmproxy**：脚本化中间人代理，可编程拦截和修改流量。

## 三、常见加密算法

### 1. AES 加密

- 加密模式：**CBC**
- 密钥长度：**128bit**
- IV向量：**16字节**

### 2. RSA 加密

网页端 RSA 加密一般使用**公钥加密**，**私钥**放在**服务端**，客户端只用公钥加密数据，服务端用私钥解密。

## 四、爬虫项目约束

1. **禁止**在未授权网站进行大规模、高频爬虫请求。
2. 接口签名参数 `timestamp` 的时间单位是**毫秒**。
